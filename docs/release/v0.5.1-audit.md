# v0.5.1 documentation audit

Scope: release preparation against main `8c378db30673de49aae533b54d783c70e2872816` (PR #53), following the v0.5.0 audit precedent. This is documentation and version metadata only, not hardware requalification. Review, merge, tagging, and publication remain separate maintainer steps.

## Structural boundaries

- `/api/v1` stays the route contract. OpenAPI is hand-maintained and embedded; only `info.version` changes here. Packaging injects version, commit, build date, and channel; development defaults and historical fixtures remain unchanged.
- Raw passthrough is an exclusive, non-preemptible byte-stream lease, including against safety. The live opt-in changes admission/arming policy, not saved arming state or actuation authority. Tapped telemetry and display temperature warnings never authorize writes.
- Gates are evidence-based, not transport-based. `internal/runtime/serial_source.go` checks native contact loss on its safety timer; `status_state.go` expires contact after five seconds. `internal/fanpolicy/policy.go` and `internal/monitoring/controller.go` require recent `status-poll` evidence. A fully stalled status/display stream loses contact; this does not prove recovery from the reported LAN-unit stall.
- No Go source, tests, dependencies, captured fixtures, installed config, or service configuration changed.
